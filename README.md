# Spina — Android

Простое Android-приложение с тремя режимами:

- **Таймер** — уведомление каждые N минут.
- **Стандарт** — уведомление при разблокировке телефона.
- **Гибрид** — оба режима одновременно.

### Сборка

1. Откройте папку проекта в Android Studio.
2. Дождитесь Gradle Sync.
3. Выберите Android Emulator или подключённый телефон.
4. Нажмите Run.

Либо из терминала после установки Gradle/Android SDK:

```bash
./gradlew assembleDebug
```

Готовый debug APK появится в `app/build/outputs/apk/debug/`.

### Важные ограничения Android

- На Android 13+ приложение запрашивает разрешение на уведомления.
- Таймер использует `setInexactRepeating`, поэтому Android может немного сдвигать время доставки для экономии батареи.
- После перезагрузки устройства таймер восстанавливается, если Spina была запущена.
- Режим «Стандарт» зависит от доставки системного события разблокировки и может вести себя по-разному на отдельных прошивках производителей.
